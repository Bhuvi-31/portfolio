Gesture Control for Browser Games

A web-based system that allows users to control browser games using real-time hand gesture recognition via webcam — no keyboard or mouse required.

Uses OpenCV & MediaPipe for real-time hand landmark detection at 30+ FPS
Maps hand gestures (swipe, pinch, hold) to browser keyboard/mouse events via JavaScript
Webcam feed processed in Python backend; commands sent to frontend over WebSocket
Works with existing browser games — no game modification required
Supports customisable gesture-to-action bindings for different game genres
